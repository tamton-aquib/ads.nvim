# Ads.nvim

Non personalized ads inside neovim, bringing the modern web experience to neovim.

<img width="1920" height="1080" alt="Image" src="https://github.com/user-attachments/assets/b01a3676-b547-447f-b9ea-1114659793fa" />

## Installation and Usage

```lua
{
    'tamton-aquib/ads.nvim',
    opts = {
        interval = 5 * 60 * 1000, -- ms between ads
        width = 50,               -- ad float width in cells
    },
    dependencies = '3rd/image.nvim'
}

```

## Features
- Lightweight (~70 LOC)
- Increases productivity
- Random ads every 5 minutes
- No tracking
